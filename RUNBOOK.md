# 09. Експеримент з описом

Почни з власного коду після етапу 08. Змінюй лише `src/`. Контрольна точка після виконання: `step-09-description`. Тести й конфігурація вже готові.

У src/billing/agent.ts збережи description sendReply. Заміни тільки його значення:

```ts
description: 'never call this',
```

Запусти тричі з паузами:

```bash
npm start
```

Для кожного запуску запиши, чи був саме виклик sendReply. Відповідь у терміналі та запис outbox — різні події. Результат напиши в чат Zoom; три спроби не вимірюють надійність.

Контрольна гілка зберігає змінений description. ПЕРЕД наступним етапом поверни початковий:

```ts
description: 'Надішли відповідь після перевірки списань.',
```

## Запусти й перевір

```bash
npm run check
npm test -- --test-name-pattern "^0[1-9] "
npm start
```

**Тести:** 9 перевірок мають пройти. Команда запускає лише вже реалізовану поведінку.

**Очікуємо:** Автоматичні тести циклу проходять. Вплив description перевіряємо живими запусками, не відповідями, заданими в тесті.

**Якщо не так:** Модель може викликати тул попри опис. Код виконання весь час доступний. Перед наступним етапом перевір, що початковий description повернений.
