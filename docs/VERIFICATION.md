# Перевірка

Дата: 2026-09-21. Цільове середовище: Node 22.19.0, `npm ci`.

## Локально

Готове рішення: 10 тестів дня 1 і 4 тести дня 2 пройшли. Усі 9 гілок пройшли typecheck, свої тести та локальний smoke; машинний звіт у `docs/branch-checks.json`.

- День 1: справжній AI SDK серіалізує HTTP до локального симулятора; перевіряємо цикл, messages 1/3/5, tool call id, паралельні виклики, обмеження кроків, 429/401, валідацію аргументів, завантаження skills, блокування outbox.
- День 2: запис/пошук на диску, ізоляція chat id, права власника, dispatch/read receipt, запуск Flue зі SQLite без моделі.
- Симулятор віддає нульовий usage; це не вимірювання токенів живої моделі.
- `npm run check` запускає typecheck і тести. Стартова гілка навмисно не має готового циклу: на ній лише foundation-тести та smoke.
- Hono перевизначено на 4.13.8: прибирає вразливість транзитивної версії Flue; сумісність покрита локальним запуском runtime.

## Ще потребує ключів

Живі виклики Groq і Gemini, справжня доставка в Telegram, збереження діалогу після перезапуску з реальною моделлю, вибір skill живою моделлю. Ці перевірки не виконані у середовищі створення репозиторію, ключі відсутні.
