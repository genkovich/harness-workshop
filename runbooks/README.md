## Тести й налагодження

[Усі сценарії агента](../test/harness.test.mjs) · [середовище та ранбуки](../test/runbooks.test.mjs) · [підміна HTTP](../test/groq.mock.mjs).

Тести мають номер теми в назві. Команда в ранбуку перевіряє цей і попередні етапи. На main та step-12-guard запускай npm test: 30 тестів. Перевіряємо структуру запитів, схеми аргументів, виконання, відповідність id, історію, ліміт, помилки, контекст, skills та дозвіл. HTTP у тестах підмінено; запит до API перевіряється окремо командою npm start із явно переданим завданням.

На етапі 09 автоматичний тест підтверджує доставку description і доступність функції. Він не вимірює, чи послухається жива модель.

Починаючи з етапу 03: TRACE=1 npm start -- "Знайди до трьох обговорень про harness engineering і coding agents за останні 7 днів. Прочитай коментарі та збережи український дайджест із посиланнями." друкує тіло HTTP-запиту. Дивись reply.toolCalls, call.toolCallId та messages. Щоб зупинити програму в потрібному місці й перевірити змінні:

```bash
node --inspect-brk --import tsx --env-file-if-exists=.env src/main.ts "Знайди до трьох обговорень про harness engineering і coding agents за останні 7 днів. Прочитай коментарі та збережи український дайджест із посиланнями."
```

У редакторі підʼєднай налагоджувач Node.js і зупинись після generateText або перед runTool. Ctrl+C завершує процес.
